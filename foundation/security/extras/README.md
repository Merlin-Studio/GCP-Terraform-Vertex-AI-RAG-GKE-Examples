# Security extras (not consumed by FAST)

The files in this directory are **not** FAST stage data: the `2-security`
stage has no factory for Cloud DLP or Cloud Armor. They are structured inputs
for the corresponding Cloud Foundation Fabric modules, to be applied from a
separate Terraform root after the security stage:

- `dlp/` — inspect templates, job triggers and de-identification templates
  (`modules/dlp-*` or the `google_data_loss_prevention_*` resources).
- `cloud-armor/` — security policies and rate-limiting rules, kept here as
  the record of what the security page asked for. They are **created** by the
  `2-security-edge` stage in this bundle, in every project that can host a
  backend service; front doors attach them by name.

Keep them next to the stage data so the intent stays in one bundle.
