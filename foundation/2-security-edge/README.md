# 2-security-edge

Security controls that are one per project, created by the landing zone in
the projects the application stages deploy into. Apply after
`2-project-factory`, as the security stage's identity.

## Cloud Armor

The policies the security page defines, created in every project that can
host a backend service. Front doors attach them by name, and a backend service
can only use a policy in its own project. Re-apply whenever the rules on the
security page change.
