# CMEK Wiring — Post-Deployment Service Agent IAM Bindings

Generated by Merlin Studio.
Run these commands AFTER `terraform apply` creates the workload projects,
since service agents require project numbers.

## Prerequisites

1. All workload projects must exist (run project factory stage first)
2. You need `roles/cloudkms.admin` on the security project
3. Set these variables:

```bash
export KMS_PROJECT="vendora-sec-core-0"
export KEYRING_EUROPE_WEST4="kr-europe-west4"
export LOCATION_EUROPE_WEST4="europe-west4"
```

## Project: app-core-0

```bash
# Get project number:
export PROJECT_NUMBER_app_core_0=$(gcloud projects describe vendora-app-core-0 --format="value(projectNumber)")

# Artifact Registry repositories
gcloud kms keys add-iam-policy-binding artifactregistry \
  --keyring=kr-europe-west4 --location=europe-west4 --project=$KMS_PROJECT \
  --member="serviceAccount:service-$PROJECT_NUMBER_app_core_0@gcp-sa-artifactregistry.iam.gserviceaccount.com" \
  --role="roles/cloudkms.cryptoKeyEncrypterDecrypter"

```
