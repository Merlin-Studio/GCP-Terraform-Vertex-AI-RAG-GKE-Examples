# 2-networking-endpoints

Private Service Connect endpoints for the regional Google APIs workloads call
from a VPC. Today that is Model Armor, which answers only at
`modelarmor.<region>.rep.googleapis.com`: a caller on a VPC reaches that name
through an endpoint like these, or gets a certificate error through Private
Google Access and VPC Service Controls.

Apply after `2-networking`, as the networking stage's identity. It needs
nothing from the workload stages, and they need nothing from it but DNS.

| Endpoint | Network | Region | Address from | Resolves |
|---|---|---|---|---|
| `modelarmor-vpc-shared-dev-europe-west4` | `vpc-shared-dev` | europe-west4 | `sb-dev-europe-west4` | `modelarmor.europe-west4.rep.googleapis.com` |
| `modelarmor-vpc-shared-prod-europe-west4` | `vpc-shared-prod` | europe-west4 | `sb-prod-europe-west4` | `modelarmor.europe-west4.rep.googleapis.com` |

Each endpoint has a private DNS zone bound to its network that resolves the
regional name to the endpoint's address, so an application calls Model Armor
by its ordinary name.

## What it costs

A Private Service Connect endpoint to a regional Google API is charged by the
hour, with no data processing charge: about $7.30 a month each, so
about $14.60 a month for the 2 above. The landing zone creates one per workload network
per region because it cannot know which applications will use Model Armor;
remove the ones for a region no application will call it from.
